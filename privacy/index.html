Informativa sulla privacy

2 minuti · Vanni | Traduzioni:
  • En

Questo blog personale è ospitato tramite GitHub Pages. Quando visiti il sito, GitHub può elaborare e registrare il tuo indirizzo IP per motivi di sicurezza. Per maggiori informazioni, consulta l’Informativa sulla privacy di GitHub.

Il sito utilizza Cloudflare Web Analytics per misurare le visualizzazioni e le prestazioni delle pagine. Il beacon invia a Cloudflare metriche di navigazione e temporizzazione. Cloudflare dichiara che Web Analytics non raccoglie né utilizza i dati personali dei visitatori e non traccia gli utenti tra i siti dei propri clienti. Per maggiori informazioni, consulta i dettagli su come vengono raccolti i dati e su Cloudflare Web Analytics.

Il sito non utilizza servizi pubblicitari. Ogni pagina carica anche lo script del pulsante Buy Me a Coffee da un CDN del servizio; la connessione può comportare il trattamento di dati tecnici, come l’indirizzo IP. Se interagisci con il pulsante, si applica l’informativa sulla privacy di Buy Me a Coffee.

Se invii un messaggio tramite il modulo di contatto, i dati inseriti vengono trasmessi a Web3Forms per inoltrarmeli via email. Web3Forms dichiara di trattare i dati sui propri server negli Stati Uniti. Consulta le informazioni di Web3Forms sulla privacy.

La ricerca viene eseguita nel browser e i termini cercati non vengono inviati a me. I link esterni portano a siti con proprie informative sulla privacy.

Questa informativa può essere aggiornata se cambiano le funzionalità del sito.
